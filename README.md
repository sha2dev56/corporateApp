CorporateApp 📍

Una aplicación móvil corporativa desarrollada con Ionic, Angular y Capacitor, diseñada para obtener la ubicación GPS en tiempo real del usuario y calcular la distancia exacta respecto a las oficinas centrales utilizando la fórmula de Haversine y los nuevos Signals de Angular.

🚀 Características

🗺️ Geolocalización nativa: Integración con @capacitor/geolocation para Android e iOS.

⚡ Reactividad moderna: Manejo de estado de la UI mediante Angular Signals.

📏 Cálculo de distancia en tiempo real: Implementación matemática del algoritmo Haversine para cálculo geodésico preciso.

📱 Interfaz Mobile-First: Diseñada utilizando componentes nativos de Ionic Framework.

🛠️ Tecnologías utilizadas

Framework: Ionic Framework

Core: Angular 16+

Runtime Nativo: Capacitor

Lenguaje: TypeScript
